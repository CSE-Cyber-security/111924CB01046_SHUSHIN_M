# To-Do-List-Application

A clean, responsive To-Do List web application designed for efficient daily task management. Developed using HTML, CSS, and vanilla JavaScript with DOM manipulation.

## Features
- Add new tasks to your list.
- Mark tasks as completed (strikethrough styling).
- Delete tasks permanently.
- Filter views by 'All', 'Pending', and 'Completed'.
- Dynamic task counters tracking pending and completed items.

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- FontAwesome (Icons)

## Usage
1. Clone the repository: `git clone https://github.com/yourusername/To-Do-List-Application.git`
2. Open `index.html` in your web browser.
